## Featured Projects

### [Production-Grade AWS EKS Platform](https://github.com/Mahin556/gowebapp-config)
**Complete end-to-end production Kubernetes deployment on AWS**

- Multi-AZ EKS cluster with external RDS database
- Secure secret management using External Secrets Operator + IRSA
- GitOps workflow with ArgoCD (auto-sync & self-healing)
- Full CI/CD pipeline with GitHub Actions (build → scan → deploy)
- Production-ready ingress with TLS termination (cert-manager + NGINX)
- Autoscaling with HPA and Cluster Autoscaler

**Tech:** AWS EKS • Terraform • Helm • ArgoCD • GitHub Actions • External Secrets

---

### [HA Kubernetes Cluster - From Scratch](https://github.com/Mahin556/highly-available-kubernetes-cluster/tree/7)
**Production-style HA Kubernetes with external etcd (bare metal)**

- Zero single points of failure architecture
- External etcd cluster with mTLS (3-node Raft quorum)
- Redundant load balancers with HAProxy + Keepalived VIP
- Multi-master control plane (3 masters, 2 workers)
- Calico CNI for pod networking

**Tech:** Kubernetes • kubeadm • etcd • HAProxy • Keepalived • Vagrant
